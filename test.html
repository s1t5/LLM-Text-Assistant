Anleitung:

  1. Lade die Extension in Chrome (Entwicklermodus → Entpackte Erweiterung laden)
  2. Klicke in eines der Felder oben
  3. Das 🤖-Icon sollte oben rechts im Feld erscheinen
  4. Klicke auf das Icon → ein Menü öffnet sich mit 4 Aktionen
  5. Wähle eine Aktion aus → der gesamte Text wird verarbeitet und ersetzt
